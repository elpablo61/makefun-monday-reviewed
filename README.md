One-line review of my own Monday, for the [make.fun bounty](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1):

> My Monday: 4 meetings, 0 decisions, and a 'quick question' from Budi at 16:47 that took until 18:20.

## How it works

`main.ts` (Node 22) writes the single review line to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` if set, otherwise `/output`). The line is 100 characters:
a deadpan micro-anecdote — a named person, exact times, concrete numbers,
one concept only — calibrated against verified top-10 winning one-liners.

## Run

```sh
node main.ts
cat /output/entry.txt
```
